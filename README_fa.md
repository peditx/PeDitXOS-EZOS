# سیستم نصب PeDitXOS-EZOS برای OpenWrt x86-64

**PeDitXOS-EZOS** یک نصاب مینیمال، هوشمند و کاربرپسند برای نسخه x86-64 از OpenWrt است که از هر دو حالت **نصب از طریق SSH** و **نصب از طریق رابط CLI با مانیتور و کیبورد** پشتیبانی می‌کند.

این پروژه مخصوص کسانی طراحی شده که نیاز به کنترل کامل شبکه دارند، به‌ویژه برای سیستم‌هایی با تنها یک پورت شبکه و نیاز به تنظیم VLAN از ابتدا.

---

## ⚙️ ویژگی‌ها

- **اجرای خودکار رابط گرافیکی (متنی) Whiptail** در هنگام بوت (چه از طریق SSH و چه از طریق ترمینال محلی)
- **نمایش رابط نصب هنگام ورود از طریق SSH** در هر بار ورود
- **پنل کنترل شبکه** با قابلیت‌های:
  - فعال‌سازی دسترسی LuCI روی پورت WAN
  - تغییر DNS از طریق چندین پریست آماده
  - شناسایی خودکار نقش پورت‌ها (WAN/LAN) و نمایش وضعیت در رابط نصب
- **تعریف VLAN از رابط گرافیکی** برای ساخت OpenWrt تنها با یک پورت فیزیکی
- **قابلیت سوییچ خودکار بین نقش WAN و Bridge** و تغییر نقش پورت‌ها به صورت کاملاً پویا از طریق رابط
- محیط نصب بدون نیاز به مرورگر، کاملاً از طریق رابط متنی قابل اجرا
- آماده‌سازی برای تبدیل کل فضای دیسک به فضای ذخیره‌سازی OpenWrt و نصب Passwall از طریق پروژه مکمل EZPasswall

## 📥 نحوه نصب

1. آخرین نسخه PeDitXOS-EZOS را از این آدرس دریافت کنید:  
   👉 [https://github.com/peditx/PeDitXOS-EZOS/releases](https://github.com/peditx/PeDitXOS-EZOS/releases)

2. با استفاده از نرم‌افزار [**Rufus**](https://rufus.ie/) ایمیج را روی یک فلش مموری بوتیبل بریزید.

3. سیستم x86 خود را از طریق فلش بوت کنید.

4. پس از نصب و ریبوت نهایی سیستم:
   - به آدرس زیر مراجعه کنید و اسکریپت را اجرا نمایید تا کل هارد برای استفاده OpenWrt پارتیشن‌بندی شده و Passwall نصب شود:  
     👉 [https://github.com/peditx/ezpasswall](https://github.com/peditx/ezpasswall)
