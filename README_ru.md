# PeDitXOS-EZOS: Инсталлятор OpenWrt x86-64 с графическим CLI

**PeDitXOS-EZOS** — это лёгкий и интуитивный установщик для OpenWrt x86-64, поддерживающий как **установку через SSH**, так и **локальную установку через CLI с монитором и клавиатурой**.

Проект ориентирован на расширенное управление сетью, особенно в условиях ограниченного количества сетевых портов.

---

## ⚙️ Возможности

- Автоматический запуск графического CLI-инсталлятора (Whiptail) при каждой загрузке (по SSH или локально)
- Каждое подключение по SSH ведёт к установщику
- Панель управления сетью:
  - Включение доступа к LuCI по порту WAN
  - Переключение между предустановленными DNS
  - Автоматическое определение WAN/LAN
- Графическая настройка VLAN — удобно даже с одним сетевым портом
- Переключение между режимами WAN и Bridge прямо из интерфейса
- Полностью терминальный интерфейс без необходимости в браузере
- После установки можно использовать [EZPasswall](https://github.com/peditx/ezpasswall) для настройки всего жёсткого диска и автоматической установки Passwall

## 📥 Установка

1. Скачайте последнюю версию с:  
   👉 [https://github.com/peditx/PeDitXOS-EZOS/releases](https://github.com/peditx/PeDitXOS-EZOS/releases)

2. Создайте загрузочную USB-флешку с помощью [**Rufus**](https://rufus.ie/).

3. Загрузите устройство с USB.

4. После установки и перезагрузки:
   - Перейдите на:  
     👉 [https://github.com/peditx/ezpasswall](https://github.com/peditx/ezpasswall)  
     и выполните скрипт для разметки диска под OpenWrt и установки Passwall.
